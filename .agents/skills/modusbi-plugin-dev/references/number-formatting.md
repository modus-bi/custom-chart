# Форматирование значений

Один модуль `CustomChart/model/format.ts` обслуживает подписи, tooltip, легенду и числовой
подзаголовок. Не дублируй toFixed/Intl по местам. Выделяй только нужные плагину функции:

| Функция | Роль | Отсутствие |
| --- | --- | --- |
| formatValue | Значение с config.precision и единицами | Видимый прочерк `—` |
| formatPercent | Доля со знаком % | null, строка исключается |
| formatPercentValue | Доля без %, знак задаёт шаблон | null |
| formatDelta | Дельта со знаком +/типографским − и единицами | null |
| formatExtra | Вспомогательная пилюля по типу поля | Прочерк |

Семантика null отличается от видимого прочерка; фильтруй null, не печатай его текстом.
Масштаб процентов (доля или уже процент) и правило для отсутствующих/нечисловых значений
берутся из задачи; если не определены — вопрос, а не автоматическое умножение на 100.

## Совпадение с порталом

Исходник требует формат ядра formatNumber/addPrefix: запятая для дробей, обычный U+0020
для разрядов, правила smallNumberClasses для чисел меньше единицы. Бери совместимую реализацию
из доступного ядра/существующего плагина и фиксируй её происхождение. Если она недоступна,
не выдумывай алгоритм и не называй Intl.NumberFormat эквивалентом; уточни источник либо
согласуй самостоятельный формат. Intl по locale/ICU может использовать другие пробелы.

При копии ядрового JS в `src/duplicates/` оставляй понятную границу и точечно настраивай lint,
не отключай правила всему проекту. Совместимость с node проверяй без window, используя
globalThis.Math или guard. Отличия локальной копии от ядра документируй рядом.
Убирай минус-ноль, включая значения, округляющиеся к нулю. Перед нативным toFixed обеспечь
допустимую конечную точность; ядровое `precision=-1` не передавай туда как есть.

## Настройки

- precision и bigNumberClasses задают готовые sections.precisionSliderContent и
  suffixSelectContent, мимо COMMANDS. Пустой/отсутствующий bigNumberClasses — полная запись;
  отдельный тумблер сокращения не нужен. Элементы набора: `{ number, prefix }`.
- `abbreviationOptions(config)` возвращает общие опции для всех мест вывода.
- Суффикс берётся из `field.units` основной пилюли с согласованным пробелом, не из нового
  текстового поля настроек без запроса пользователя.
- formatExtra не наследует единицы основной пилюли: number форматируется как число,
  date — по dateFormat, текст остаётся текстом. Формат даты/часовой пояс уточни, если не заданы.
- Собственные precisionPercent/dateFormat вводятся по [настройкам](new-setting.md) и читаются
  через readConfigField в старых отчётах; 0 — валидная точность. bigNumberClasses может быть
  необязательным без JSON-дефолта, поскольку отсутствие само задаёт поведение.

Проверяй отрицательные значения, -0, округление к нулю, точность 0/-1, дроби <1, классы
сокращения и их отсутствие, U+0020, null/undefined, нечисловой extra, единицы и согласованность
всех мест вывода. Эталонные строки должны следовать подтверждённым требованиям/ядру.
