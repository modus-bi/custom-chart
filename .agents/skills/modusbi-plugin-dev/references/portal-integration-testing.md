# Портал: среда и матрица

Портал подтверждает интеграцию с ядром, CSS, реальным ответом и сохранением. Локальные unit-тесты
этого не доказывают. Полный базовый прогон нужен для нового плагина/релиза и изменений общего
контракта; узкая правка — затронутые сценарии и регрессия по diff. Процесс — [UC](uc-testing.md).

## Подготовка

1. Используй тестовую среду и выделенный отчёт. Проверь разрешённый объём изменений перед
   созданием/сохранением объектов или установкой плагина; прежнее явное разрешение учитывается.
   Запрос на локальную сборку сам по себе не разрешает публикацию или изменение чужого отчёта.
2. Ядро целевого портала распаковано в prebuild вместе с подставленной конфигурацией бэкенда.
   `rg -q '#config#' prebuild/index.html`: код 0 означает оставшийся placeholder, 1 — его
   отсутствие, >1 — ошибка чтения. Не печатай весь конфиг и не редактируй поставку, чтобы
   скрыть дефект распаковки; получи правильную поставку.
3. `npm start` раздаёт локальный плагин в нулевом слоте `/plugins/custom_chart_0.js`.
   Порт из webpack/PORT (исходно 7000). Отчёт-полигон должен содержать **CustomChart0**;
   иной слот может показывать прежний установленный плагин.
4. Используй доступный браузерный инструмент с шагами, console/network и артефактами
   (Playwright MCP подходит). Названия tools обнаруживай в текущей среде; `.mcp.json`
   Claude сам не подключает их в Codex. Не делай конкретное имя MCP обязательным.
5. Если сессии нет, пользователь выполняет вход сам. Не проси пароль/токен в переписке;
   продолжай с авторизованной сессией. Не предполагается, что существует `.playwright-mcp/`
   или гарантированно сохраняется профиль: это зависит от инструмента.

Без браузерных инструментов подготовь точные ручные шаги и запроси наблюдения пользователя;
пометь ручной результат отдельно. Отсутствие MCP не мешает написать UC и выполнить локальные
проверки. API/MCP портала используют только если доступны и разрешены; создание полигона
вручную допустимо с записью действий и ограничения воспроизводимости.

Полигон: текстовое/числовое поля, несколько значений/категорий в поддерживаемом режиме,
фильтр, null/пустая выборка, данные выше лимита. Сохрани обезличенную фикстуру и согласованный
config, а не производственные данные. Существующий пользовательский отчёт не присваивай себе.

## Матрица

| Группа | Проверки |
| --- | --- |
| Загрузка | Компонент доступен в палитре, добавляется, нет ошибок загрузки/экспортов |
| Полки | Имена/иконки/порядок; drop сохраняет поле; ёмкость меняет активность; меню не теряет нужные пункты |
| Данные | Запрос непустой; трейсы соответствуют активным полям; несколько категорий; фильтр влияет на ответ |
| Кэш | Ответ читается через data и datas[cacheId] по ситуации; смена полей/параметров обновляет выборку |
| Обновление | reloadDatas по интервалу; выключение/размонтирование убирает таймер; нет лишних запросов |
| Настройки | Своя команда изменяет нужное поле; auto/manual apply; значения не теряются после сохранения |
| Совместимость | Старый конфиг без новых полей, false/0/null, пустота и ошибки отображаются согласованно |
| Оболочка | Тема, длинный заголовок, фон, кнопки ядра, описание на обороте **в отчёте** |
| Движок | Resize плитки, переключение вкладок, повторное открытие, легенда/зум, нет накопления canvas/svg |
| Интерактив | Cursor, filter/Ctrl, drill-down и возврат в поддерживаемых режимах |
| Установка | Проверенный архив работает после разрешённой установки в назначенный порталом слот |

Не применимые функции отмечай N/A с причиной, а не требуй реализовать их все. Например,
плагин без ECharts не обязан поддержать dataZoom. Запрет drop не диагностируется одним
isDisabledAxe — этот метод отвечает за неактивный вид пилюли.

Продуктовый UC описывает действия, ожидаемый наблюдаемый эффект и признак сбоя. Файл
`docs/uc-<фича>.md` в плагине, артефакты — в разрешённом локальном каталоге без секретов.
Скриншоты подтверждают наблюдение, но не заменяют проверку данных/команд. Не вводи обязательный
pixel diff диаграмм без необходимости: анимация и антиалиасинг делают его нестабильным.
